# Tourism Management System - WPF Application

## Project Overview

This project is an academic assignment developed for two university courses:

- **Human-Computer Interaction (HCI)**
- **Simulation and System Modeling**

The goal of the project was to develop a tourism management application using the WPF (Windows Presentation Foundation) technology, following the MVVM (Model-View-ViewModel) design pattern. The application provides functionality for booking accommodations, creating and reserving tours, and more.

## Key Features:

- Users can interact with the application in one of the following roles:

  - **Guest**
  - **Owner**
  - **Tour Guide**

- Each role offers specific functionalities:
  - **Guests** can book accommodations and tours.
  - **Owners** can manage their properties and bookings.
  - **Tour guides** can create and manage tours.

### Simulation and System Modeling Component:

The primary task for this course was to simulate a solution for problems related to the tourism industry. Each team member was responsible for developing functionalities related to one user role, ensuring a seamless system for managing tourism-related tasks.

### Human-Computer Interaction Component:

For this course, the focus was on developing a user interface (UI) tailored to specific types of users. Each team member developed a UI considering different user needs, such as:

- Users with color blindness
- Elderly users
- Users unfamiliar with technology
- Tech-savvy users who need quick access to functionalities

This approach ensures that the application is accessible and easy to use for a wide range of users, enhancing overall usability.

## Usage

Once the application is running, users can log in as a Guest, Owner, or Tour Guide and use the corresponding features:

- Guests can search for accommodations and tours, make bookings, and manage their reservations.
- Owners can create and manage properties, review bookings, and communicate with guests.
- Tour Guides can create and manage tours, and view upcoming bookings for their tours.

Each role's interface is designed with specific user groups in mind, providing personalized user experiences based on the guidelines from the HCI course.
